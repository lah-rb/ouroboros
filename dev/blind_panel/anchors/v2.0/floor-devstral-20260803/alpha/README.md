# Text Adventure Game

A fun text adventure game built in Python. Explore a world, fight monsters, solve puzzles, and defeat the final boss!

## Features
- Movement in four directions (north, south, east, west)
- Inventory management (take, drop, use, examine, equip)
- Conversation with NPCs
- Turn-based combat with health and stats
- Save/load functionality

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/text-adventure-game.git
   cd text-adventure-game
   ```
2. Install dependencies:
   ```sh
   pip install -e .
   ```

## Running the Game
Start the game with:
```sh
python main.py
```

## Controls
- `go [direction]` - Move in a direction (north, south, east, west)
- `take [item]` - Pick up an item
- `drop [item]` - Drop an item
- `use [item]` - Use an item
- `examine [item]` - Examine an item
- `equip [item]` - Equip an item
- `talk to [npc]` - Talk to an NPC
- `attack` - Attack a monster
- `flee` - Flee from combat
- `look` - Look around the current room
- `status` - Show player status
- `help` - Show available commands
- `quit` - Quit the game

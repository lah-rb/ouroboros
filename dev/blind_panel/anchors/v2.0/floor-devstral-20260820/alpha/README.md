# Text Adventure Game

A text adventure game with combat, inventory, and exploration.

## Features

- Movement (go north/south/east/west)
- Inventory handling (take, drop, use, examine, equip)
- Conversation (talk to)
- Combat (attack, flee)
- Utilities: look, status, help, quit
- Turn-based combat with health and attack power
- Weapons, armor, and healing items
- Save and load functionality

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/text-adventure-game.git
   cd text-adventure-game
   ```

2. Install dependencies:
   ```sh
   pip install -e .
   ```

3. Run the game:
   ```sh
   python main.py
   ```

## Controls

- Type commands to interact with the world.
- Use `help` to see available commands.
- Use `quit` to exit the game.

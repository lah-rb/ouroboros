# Raw judge records

One file per judge, verbatim, as returned. They are kept because the results
summary is a synthesis and a synthesis is not auditable against itself — the
conformance spread, the HP-margin disagreement and the three independent
instrument objections are only checkable here.

`*_KEY.json` maps the staged label to the config. It is NOT part of a packet and
must never be pasted into a judge prompt.

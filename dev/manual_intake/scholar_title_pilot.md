# Scholar exact-title pilot: 10 unresolved papers

Drawn 2026-09-24 with seed 20260924: a simple random sample from the 4,100 `oa_unresolved` papers in the databank. The pool splits into bot wall 45% (HTTP 403 or an HTML page), dead link 45% (HTTP 404/400) and other 10%. Each link searches Google Scholar for the exact title in quotes, and nothing else.

**How to run it**

1. Note the start time.
2. Open each link. A hit is a free full-text PDF of the same paper, whatever the host: the `[PDF]` link on the right, or *All N versions*. An abstract page, a paywall or a different paper is a miss.
3. Save hits to `~/Downloads` under any file name. I'll match them to their records by the first page.
4. Tick the box and note the host (academia.edu, ResearchGate, university repository, publisher, …) and roughly how long each took.
5. Note the end time at the bottom.

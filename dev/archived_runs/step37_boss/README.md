# Text Adventure

A command-line text adventure game built in Python. The engine loads world data from YAML files, featuring turn-based combat, inventory management, NPC interactions, and save/load functionality.

## Features

- YAML-driven world definition (rooms, items, NPCs, monsters)
- Movement, inventory, and interaction commands
- Turn-based combat with equipment and healing
- Final boss with two phases and a hidden weakness
- Save/load game state to JSON
- Playable demo world with 8+ rooms and branching content

## Requirements

- Python 3.11+
- PyYAML

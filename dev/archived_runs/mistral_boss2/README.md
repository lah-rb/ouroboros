# Text Adventure Game

A Python-based text adventure game with:
- Turn-based combat system (player stats, equipment, healing)
- YAML-based world definition (rooms, items, NPCs, monsters)
- Command parser for movement, inventory, interaction, and combat
- Save/load game state to JSON
- Final boss with two phases and a hidden weakness

## Requirements
- Python 3.10+
- PyYAML

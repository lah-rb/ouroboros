# Text Adventure Game

A Python‑based, turn‑based text adventure game featuring:

- A rich, YAML‑driven world with rooms, items, NPCs, monsters, and a multi‑phase boss.
- Command parser handling movement, inventory, combat, NPC interaction, and more.
- Persistent save/load functionality (JSON).
- Engaging narrative with descriptive text and combat narration.

## Requirements

- Python 3.9 or newer
- Dependencies are managed via **pyproject.toml** (see below)

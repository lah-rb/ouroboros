# Text Adventure Game

A Python command‑line text adventure that features:

- A rich world loaded from `world.yaml`
- Movement, inventory management, and NPC interaction
- Turn‑based combat with weapons, armor, healing items, and a multi‑phase final boss
- Save and load of full game state to JSON
- A demo world with 8 rooms, items, NPCs, monsters, and a hidden boss weakness

## Prerequisites

- Python 3.9 or newer
- The dependencies listed in `pyproject.toml` (installed via `pip install .`)
